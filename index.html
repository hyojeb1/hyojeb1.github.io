상용 엔진 없이 Direct2D 위에 3주 만에 올린 UI 중심 성장 게임에서 씬과 UI 골격을 맡았습니다. 초기 구조는 버튼만 마우스 입력을 받아서, 클릭이 필요한 요소가 늘 때마다 버튼인 척하는 오브젝트를 만들어야 했고 좌표도 절대값이라 창 크기가 바뀌면 배치가 어긋났습니다. 입력을 MouseListenerComponent로 떼어내 어떤 오브젝트에든 붙게 하고 좌표를 상대값으로 옮겼습니다. 화면에 박혀 있던 대사도 파일에서 읽도록 분리해, 튜토리얼과 엔딩 문구를 코드 수정 없이 고칠 수 있게 했습니다.
